# Feature request

Implement the approved initial release of `plgonzalezrx8/uptime-kuma-mcp` as a clean-room, MIT-licensed Python FastMCP server.

The release must be Docker Compose-first, bearer-authenticated over Streamable HTTP, read-only by default, secret-safe, and compatible with exactly Uptime Kuma 2.5.0. It must expose the approved Phase 1 read-only tools, fail closed on any other Kuma version, include real contract tests against the digest-pinned Kuma container, and be suitable for open-source publication.

Approval record: Pedro Gonzalez wrote “I approve, proceed” in Hermes WebUI on 2026-08-08 after reviewing the revised proposal.
